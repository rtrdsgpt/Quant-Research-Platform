# Quant Research Platform — core dependencies.
#
# This is everything the pipeline, API, and test suite need. Two things
# are deliberately kept out of this file, each in its own requirements
# file, because neither is a hard runtime dependency of src/ or tests/:
#   - requirements-optional.txt: torch/transformers/tensorflow. The code
#     that would use them (FinBERT sentiment, autoencoder stock
#     selection in the legacy replication mode) already has a designed
#     graceful fallback (synthetic sentiment / PCA) when they're
#     missing -- see src/data/sentiment_data.py and
#     src/construction/selection.py. Installing them is only needed for
#     the *real* (non-synthetic/non-PCA) behaviour, not for the pipeline
#     to run or the tests to pass.
#   - requirements-dev.txt: jupyter/ipykernel (notebook exploration) and
#     dvc (a standalone CLI tool, never imported by Python code).
#
# CI (.github/workflows/ci.yml) installs only this file -- installing the
# full stack (esp. torch, which pulls several GB of CUDA libraries on
# Linux unless given a CPU-only index) exhausted a GitHub-hosted runner's
# disk. Docker installs this + requirements-optional.txt (see Dockerfile
# for the CPU-only torch fix). Local dev: add -r requirements-dev.txt too.
